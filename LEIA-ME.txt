CONFIGURAÇÃO MANUAL NECESSÁRIA (NÃO INFORMAR O TOKEN AO CHATGPT)
1. Criar um token pessoal no endereço https://lichess.org/account/oauth/token com nenhum escopo extra, se possível.
2. No repositório Github: Settings -> Secrets and variables -> Actions -> New repository secret.
3. Nome exato: LICHESS_API_TOKEN; valor: token completo. Não usar Variables, e não incluir no Git.
4. Extrair ZIP e publicar commit/push.
5. Actions -> Publicar campeonato -> Run workflow; verificar 'autenticação habilitada' e redução dos HTTP 401.
